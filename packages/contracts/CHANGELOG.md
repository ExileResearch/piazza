# Contract changes

## 1.0.0 — 2026-10-24

First private interface baseline after plan 00 phases 1–5. Adds the executable product/protocol route catalog, private party queries, reviewable action intents, bounded events and reference-only receipt recovery, OAuth/MCP profile and shared-use-case mappings, generated OpenAPI/tool artifacts, representative generated Freezed models and compatibility gates. Preserves earlier auth, identity/control, lifecycle, evidence, social, artifact and privacy invariants.

This version closes the contract gate for backend work. It does not announce a running API or application release. See [decision 0004](../../.docs/decisions/0004-contract-baseline.md) for compatibility rules and evidence limits.
